Questions About Your Aurora Request

What should I check about the return-air path in Aurora?

If a return duct passes through a basement or another dusty area, ask whether its joints and connections will be checked for leakage. Return-side gaps can draw air from outside the intended path, but their presence should be confirmed rather than assumed. Knowing which return sections are included makes the repair scope easier to compare.

How can I compare the scope after inspection for a Aurora property?

Ask for an inspection-based description of rooftop units, make-up air equipment and long duct runs, including exclusions and access assumptions. Compare proposals by the equipment and sections named, not just the overall label of the service. Differences in system layout can change labour and access requirements, so the written scope should explain the basis for the work.

For air duct cleaning in Aurora, how should I inspect returns and grilles?

If leaves, pollen or other seasonal debris collect near a return grille, photograph the area and ask whether the return path and nearby duct sections need inspection. Debris at one grille does not establish the condition of the whole system. This check helps distinguish a local buildup from a wider cleaning scope.

What should I check about the dryer connection in Aurora?

Before arranging work, note visible lint around the dryer connection and photograph the area if it is safely accessible. Ask how the connection will be handled and whether lint will be removed from the full vent route. Lint buildup can restrict exhaust, so knowing which sections are included helps clarify the work required.

What should I check about the HRV core and drain in Aurora?

If the home has an HRV, ask whether the core, screens and condensate path will be inspected and cleaned, and whether the manufacturer's guidance affects the method. Share the unit model and photograph visible labels. Core access and drain condition change the scope; cleaning should not be described as restoring a particular performance figure without measurement.
